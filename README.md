# Flexbox Quest

A simple mini-game page made with HTML and CSS for practicing Flexbox.

## Open the page

Open index.html in a web browser. No installation is needed.

## What it includes

- A game header and a visual game area
- Controls, inventory, and quest panels
- A small demonstration of block, inline, inline-block, and flex
- A responsive layout that stacks the panels on smaller screens

## CSS concepts

The page practices Flexbox, the box model, background colors, spacing, and a media query. It uses no JavaScript, CSS Grid, positioning, or CSS framework.

## Files

- index.html — page content and structure
- style.css — colors, layout, and responsive styles
